# Ruta Chévere

Prototipo web para compartir rutas entre conductores y pasajeros.

## Tecnologías

- HTML, CSS y JavaScript.
- PHP 8 para la API.
- JSON para persistencia local.
- Google Maps para mostrar rutas.

## Inicio rápido

```powershell
php -S localhost:8000
```

Abre `http://localhost:8000/index.html`.
