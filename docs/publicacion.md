# Publicación

GitHub almacena y muestra el código, pero GitHub Pages no ejecuta PHP.

Para usar el backend en Internet se necesita un hosting con PHP, como Hostinger, Render o Railway.

## Publicar GitHub

```powershell
git add .
git commit -m "Documentar proyecto"
git push origin main
```

## Importante

- `index.html` contiene la interfaz.
- `api.php` requiere PHP en el servidor.
- GitHub Pages no puede guardar datos en `data/rutachevere.json`.
