# Datos personales

La aplicación procesa nombres, teléfonos y documentos.

## Recomendaciones

- Obtén autorización antes de recolectarlos.
- Usa HTTPS en el sitio público.
- Protege `config.local.php`.
- Cambia la contraseña del panel administrativo.
- Limita el acceso a administradores.
- Permite consultar, corregir o eliminar datos.

## Colombia

Para uso real, revisa la Ley 1581 de 2012 y sus decretos reglamentarios.
